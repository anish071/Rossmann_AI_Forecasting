# 📈 Rossmann AI Sales Forecasting

An end-to-end Machine Learning web application for forecasting Rossmann store sales and customer demand.

## 🚀 Live Demo

👉 https://rossmannaiforecasting-3sokesuqkxpwthgbx2c6fj.streamlit.app/

## 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest
- LSTM
- Plotly
- Streamlit
- Hugging Face Hub

## ✨ Features

- 6-week sales forecasting
- Customer prediction
- Store-wise forecasting
- Interactive visualizations
- CSV upload & batch prediction
- Forecast CSV download
- Model performance metrics
- Premium Streamlit dashboard
